# iPhone 11 Home Screen web app adjustments

These changes address behavior observed on an iPhone 11 when Elementary was added to the Home Screen. The gesture and hamburger adjustments detect iOS/iPadOS standalone mode, so they can also affect other iPhones and iPads. The top border change applies to the web reader in any browser when the navigation pane is in minimal mode.

## What changed and how to undo it

| Adjustment | Where it lives | How to undo it |
| --- | --- | --- |
| Larger hamburger and better spacing | [MainPage.Navigation.cs](../src/Elementary.Uno/Elementary.Uno/MainPage.Navigation.cs) scales the glyph from 16 to 22. It centers the button beside Book and Chapter while the minimal pane is closed, restores its usual position when the pane opens, and leaves room above Streak and Settings. | Revert `0eba06e` to undo the complete adjustment, including the iOS standalone check added to [index.html](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/index.html) and [BrowserNavigationGesture.cs](../src/Elementary.Uno/Elementary.Uno/Services/BrowserNavigationGesture.cs). |
| Swipe right from the left edge to open navigation | [index.html](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/index.html) detects an inward swipe just inside the left edge. [BrowserNavigationGesture.cs](../src/Elementary.Uno/Elementary.Uno/Services/BrowserNavigationGesture.cs) connects that gesture to `OpenNavigationPaneFromSwipe` in [MainPage.Navigation.cs](../src/Elementary.Uno/Elementary.Uno/MainPage.Navigation.cs). | Remove the left-edge touch listeners and `elementarySetLeftEdgeSwipeHandler` from the HTML, then remove the corresponding import, load and unload registrations, and `OpenNavigationPaneFromSwipe`. Keep `IsIosStandalone` if the hamburger adjustment is still in use. |
| Blue Bible Home Screen icon | [index.html](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/index.html) declares [apple-touch-icon.png](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/wwwroot/apple-touch-icon.png) explicitly because the intended artwork wasn't appearing on the iPhone Home Screen. | Remove the `apple-touch-icon` link and PNG together to fall back to the web manifest icons. The icon and left swipe share commit `e11d70a` with the production and Beta renames, so undo them selectively if keeping the names. |
| Hide the top hairline when the pane is fully collapsed | [MainPage.xaml](../src/Elementary.Uno/Elementary.Uno/MainPage.xaml) overrides the minimal pane's default top border. `UpdateNavigationContentBorder` in [MainPage.Navigation.cs](../src/Elementary.Uno/Elementary.Uno/MainPage.Navigation.cs) restores the line when that pane opens. | Remove the `NavigationViewMinimalContentGridBorderThickness` override, the border brush on `NavigationContent`, and `UpdateNavigationContentBorder` with its two subscriptions. Keep the named grid if the hamburger spacing code still uses it. Commit `9db552f` also removed the deprecated iOS `black-translucent` status-bar tag. That experiment did not remove the hairline, so there is no need to restore the tag when undoing the border change. |
| Bottom Home Screen gesture protection | [SafeArea.css](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/WasmCSS/SafeArea.css) and [index.html](../src/Elementary.Uno/Elementary.Uno/Platforms/WebAssembly/index.html) put a transparent strip over the bottom of the reader and keep Uno from handling touches that start there. This leaves the iOS home and app-switch gestures available without reserving layout space. | Remove the bottom strip markup, CSS, and event interception together. Keep the iOS standalone detection while swipe-to-open or the hamburger layout uses it. See `4d8efda` and `cf39eab` for the original changes. |

Opening the minimal pane still moves the reader down by one layout pixel because its restored border takes up space. This was reproduced in a browser with iPhone-sized viewport settings and left as-is. Drawing the line over the content would preserve the visual border without moving the reader.

If removing the bottom strip while keeping swipe-to-open, also remove the swipe handler's `event.target === gestureArea` check. If removing both navigation adjustments, undo the hamburger change before deleting `BrowserNavigationGesture.cs`.

After a rollback, check [Elementary Beta](https://preview.elementary.grantstreetdesign.com) from the iPhone Home Screen. Check the closed and open pane, Streak and Settings headers, and the left-edge and bottom gestures. For an icon change, check the artwork shown in Safari's **Add to Home Screen** flow.
