# Changelog

### v0.8.0

### Added or Changed

* Added KJV and ASV Bible translations.
* Added navigation history with flyout and ability to jump back to previous locations.
* Improved top-of-reader blur with a more progressive fade using the Composition API.

### v0.7.0

### Added or Changed

* Refactored Bible loading to use USFM format across all translations.
* Improved settings persistence and reliability.
* Minor UI polish and stability improvements.

### v0.6.0

### Added or Changed

* Navigation history tracking — the app now remembers the last 10 locations visited.

### v0.5.0

### Added or Changed

* Added KJV translation support.
* Added ASV translation support.

### v0.4.0

### Added or Changed

* Add verse of the day functionality.

### v0.3.0

### Added or Changed

* Remembers the location last navigated to.
* Fixed bug where chapter did not scroll to top after changing chapter.
* Added 3 font sizes and 2 font options.
* Added settings for theme.

## v0.2.0

### Added or Changed

- Dramatically improved touch scrolling performance.

## v0.1.3

### Added or Changed

- Improve caption button color in light mode on Windows 10.

- Handle theme change for caption buttons in Windows 10.
* Adjust sizing on Settings page

## v0.1.2

### Added or Changed

* Fixed crash when launching app with narrow window width.
* Fixed wrong themed splash screen and start menu tile in light mode.

## v0.1.1

### Added or Changed

- Other miscellaneous improvements.

## v0.1.0
